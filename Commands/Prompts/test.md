Create a complete, self-contained website using HTML and Tailwind CSS that can be run directly in a browser without any build process.

Requirements:
1. Create a single HTML file named "index.html"
2. Use Tailwind CSS via CDN (no build step required)
3. Include a modern, responsive design
4. Add interactive JavaScript functionality
5. The website should showcase your capabilities

The website should include:
- A hero section with a gradient background
- A navigation bar with smooth scroll to sections
- An "About" section with cards
- A "Features" section with icons and descriptions
- A "Contact" form with validation
- A footer with links
- Dark mode toggle functionality
- Smooth animations and transitions
- Mobile-responsive design

Use modern Tailwind CSS classes and make it visually appealing. Include inline JavaScript for interactivity. The entire website should be in a single HTML file that can be opened directly in any modern web browser.
